## Start here

This repository contains Daniel Bourke’s beginner-friendly, code-first PyTorch course materials: notebooks, exercises, slides, models, helper code, and deployment examples.

1. Start with **00 — PyTorch Fundamentals**.
2. Open a notebook in Google Colab or Jupyter.
3. Run cells, change values, and observe the results.
4. Progress through workflow, classification, vision, custom datasets, modular code, transfer learning, experiment tracking, paper replication, and deployment.

The course reports **321 published videos** and completed materials for sections 00–09. It expects basic Python, introductory machine-learning familiarity, and willingness to experiment.
